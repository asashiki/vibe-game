# Vibe 游戏开发手册

一本实用的、持续更新的「Vibe 游戏开发」手册。通过「vibe coding」的方式，利用 AI（尤其是 Claude Fable 5 等强大模型）结合现代工具，从想法快速到达可玩原型。

本仓库已从最初的 3D/VR 想法收集仓库，转变为专注于 AI 辅助游戏开发的实用手册。

## 语言版本

- English: [AI-Game-Dev-Guide.md](./AI-Game-Dev-Guide.md)
- 中文: [AI-Game-Dev-Guide.zh.md](./AI-Game-Dev-Guide.zh.md)

## 什么是「Vibe 游戏开发」？

Vibe coding 指的是用较高层次的描述告诉 AI 你想要什么，然后让强大的模型（结合图像生成、3D 工具、MCP 服务器等）承担大部分实现、迭代甚至资产整合的工作。

本手册聚焦 2026 年真实有效的实践模式：
- 使用 Claude Fable 5（及类似模型）快速完成完整游戏原型
- 混合工作流（AI 图像生成 + AI 写代码）
- 2D、3D（Three.js）、Godot、Unity、VRChat 以及无引擎开发
- 资产管线（2D、3D、音频）
- 实用资源和社区案例

## 内容概览

手册主要涵盖：
- Fable 5 在游戏开发中的能力
- 2D 游戏（弹幕射击、音游、像素游戏、平台跳跃等）
- 使用 Three.js 的 3D Web 体验
- Image-2 + 代码混合工作流
- 摄像头 / MediaPipe 交互
- VR / VRChat 开发
- 引擎 + MCP 完整管线（Godot、Unity、Blender）
- 文字冒险 / ADV / Galgame 类游戏
- 程序生成与旧游戏逆向重制
- AI 美术、3D 建模（Seed3D、Meshy 等）和音频管线
- 资源获取与社区项目

## 开始使用

1. 阅读你偏好的语言版本手册。
2. 选择一个小项目开始（比如给之前用 Fable 5 做的游戏加上更好的美术或音频）。
3. 参考手册中的工作流和工具推荐进行实践。
4. 分享你的经验！
